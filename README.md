# CropAI — AI-Powered Crop Health & Disease Analysis

CropAI is a production-ready, multimodal agronomical diagnosis web application powered by Google Gemini and Node.js. Upload a photo of your crop to instantly identify plant species, detect disease symptoms, calculate affected vs. healthy foliage ratio, estimate field-scale impact, and get safe fertilization recommendations.

---

## 🚀 1. Installation

Clone or extract the repository and install all dependencies:

```bash
git clone https://github.com/your-username/crop-ai.git
cd crop-ai
npm install
```
